# UNDANGAN PERNIKAHAN RIZAL DAN NAISYA

## TEKNOLOGI YANG DIGUNAKAN
-  HTML
-  CSS
-  JavaScript

## FITUR

-  Animasi pembukaan undangan
-  Informasi acara pernikahan
-  Desain fleksibel berbagai perangkat
